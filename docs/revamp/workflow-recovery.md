# Verk observation and notification recovery

Resuming a paused phase without a recorded output retains its attempt and request ID. A completed durable delegation receipt is required before observation resumes. The native observer is reattached and the same job is followed; unavailable or uncertain admission remains paused rather than starting another job. Recovery text does not alter the pinned execution context. A genuinely BLOCKED phase still starts a new attempt with the owner's clarification.

Cancellation visits retained attempt receipts, not only the latest handle. Unknown admission remains explicitly unconfirmed. A receipt arriving after cancellation triggers cancellation of the newly known handle; cancellation never undoes earlier external effects.

Notification delivery records its exact input before submission. A lost acknowledgement retains the event ID and payload. An authenticated owner can POST `/api/tasks/{id}/retry-notification` with `{"event_id":"<event_id from notification_failed message>"}` and the normal CSRF header. Only the current completed or blocked task notification is eligible; stale IDs, unknown receipts and nonterminal states are rejected. A completed receipt is idempotent. This one-shot request performs no phase execution or classification and has no automatic retry loop. Resume changes the eligible notification identity, so requests checked after resume reject the old blocked-state event. A retry already admitted when resume occurs may still deliver the old notification: its saved status, payload, event ID and originating turn remain pinned, never rewritten to describe later work. Owner notification calls are serialized within the manager; this is not an atomic transaction with remote delivery or task resume.

The retry endpoint recovers only an already persisted notification intent. A process failure between terminal classification and the first notification journal write has no such intent and is rejected as unknown; this mechanism does not claim atomic terminal-state/delivery creation or automatic crash recovery for that window.
