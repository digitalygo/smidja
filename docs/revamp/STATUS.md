# Revamp implementation status

This is an incremental draft, not a deployment or a declaration that every acceptance criterion is complete.

## Implemented in this branch

- Authenticated single-owner manager and embedded browser UI, JSONL sessions/tasks/tool receipts, restart recovery with explicit uncertainty.
- Envai ATP v3 adapter, request signatures and native delegation/delivery/classification contracts. Verk phase completion waits for the delegated **job**, not its first turn acknowledgement.
- Sequential Tafla with exact phase outputs, classifier-only retry and blocked-phase resume; native cancellation acknowledgement and uncertain cancellation remain distinguishable. Cancelling a task also stops its exclusive phase observers and their active local/client tool contexts, without stopping unrelated Smidr conversations.
- Bounded Verk input schemas and pinned allowed-invoker policies; authenticated owner access is separate from agent identity derived from persisted remote chat/Lid provenance.
- Owner-managed per-client pairing, explicit rotation and durable revocation with hashed credentials, one-time token display and restart-safe rejection of revoked static credentials.
- Generic OS-permission machine tools, outgoing authenticated clients, online/offline inventory, text editing with conflict checks and Git diff.
- Public/private package sources, verified immutable releases, periodic updates, pinned Verk Lid and tools, retained execution routes across restart, client-owned package capabilities and lazy skills.
- Private Lid/Verk/extension proposals, owner approval, revision checks and recoverable archive. Approved manager/client extensions execute with explicitly referenced environment variables. Client activation propagates authenticated revisioned controls, remains visible while pending/offline and rejects new stale calls immediately. Existing actions may finish before a serial client applies archive.
- Smidr Lid discovery/delegation, Verk and client tools; client namespaces distinguish otherwise identical Lid/tools.
- Strict configured root model admission for Smidr and Lid/Verk delegates, targeting Envai PR #56 commit c907371b252244cf7a2475d6326e90a28da82880.
- Read-only four-phase PR review with manual API/Smidr/UI entry, pinned base/head SHAs, full diff and exact-head CI evidence, focus and optional repository/organization polling using the same Tafla and deduplication. No automatic code execution or GitHub publication.
- Independent code review and offline race tests. CI includes changed-code coverage gates, four build targets, mocked DOM checks and a sandboxed browser smoke job.
